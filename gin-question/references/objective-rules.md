# gin-question 客观化规则手册

## 1. QM1-QM3 过滤规则

### QM1：真问题判定

| 要素 | 代理指标 | 判断标准 |
|---|---|---|
| 主体真实 | 来源真实 | 问题必须来自真实网页 URL |
| 缺口真实 | 疑问句式 | 句子以问号结尾或含疑问词 |
| 意图真实 | 可客观回答 | 不属 QM3-D 不可证伪类 |

### QM2：有效问题判定

| 规则 | 代理指标 | 判断标准 |
|---|---|---|
| 真实性 | 有 source_url | 必须附带真实网页来源 |
| 认知性 | 疑问句式 | 以？/吗/呢/怎么/什么/为什么等结尾 |
| 客观性 | 不含主观词 | 不含"好不好""值不值得""喜不喜欢"等 |
| 价值性 | 频次或来源 | 频次 ≥ 2 或来源为一级/二级 |

### QM3：假问题剔除

#### QM3-A 虚构类

| 判断标准 | 例子 |
|---|---|
| 含"可能有人问""有人好奇""假设你问" | ❌ |
| 表述过于完整、教科书化 | ❌ |
| 来源是 AI 生成内容聚合页 | ❌ |

#### QM3-B 修辞/功能类

| 判断标准 | 例子 |
|---|---|
| 反问语气结尾："这还用说吗？""难道不是吗？" | ❌ |
| 情绪宣泄："这特么不是坑人吗？" | ❌ |
| 本质是命令/建议："你为什么不试试..." | ❌ |

#### QM3-C 无真实搜索意图类

| 判断标准 | 例子 |
|---|---|
| 文本长度 < 5 字 | ❌ |
| 缺少主语/谓语/宾语 | ❌ |
| 含过度抽象词："人生""世界""一切""永远""意义" | ❌ |
| 含 AI 倒推词："可能有人问""有人好奇""假设" | ❌ |

**注意**：简单常识问题如果有真实来源，保留，交给频次门槛过滤。

#### QM3-D 不可证伪类

| 判断标准 | 例子 |
|---|---|
| 含主观价值词："好不好""值不值得""应不应该" | ❌ |
| 含未来预测词："未来会不会""以后会怎么样" | ❌ |
| 含个人偏好词："你喜欢""我觉得" | ❌ |

#### QM3-E 补充类

| 判断标准 | 例子 |
|---|---|
| 文本严重残缺 | ❌ |
| 是另一个问题的完全重复 | ❌ |
| 无效二元："减脂吗？""水？" | ❌ |

## 2. 疑问句正则模式

```regex
# 以问号结尾
^.*?[？?]$

# 含疑问词
^.*?(吗|呢|么|怎么|什么|为什么|为何|多少|哪些|哪个|是不是|能不能|可不可以|如何|哪里|何时|谁).*?[？?]?$
```

过滤后需 LLM 二筛。

## 4. 去重规则

### 精确去重

1. 去除首尾空格
2. 统一标点（中文问号、英文问号统一为中文）
3. 繁简转换
4. 字符串比对

### 语义去重

- 相似度阈值：0.85
- 保留来源更多的问题
- 来源数相同则保留限定更具体的问题

### 子集去重

- 如果问题 A 是问题 B 的完整子集
- 保留限定更具体的 B
- A 记入 B 的 `duplicates`

## 6. 输出禁区（防 AI 味）

问题文本中避免：
- 套话："首先...其次...最后""综上所述""值得注意的是"
- 空洞形容词："赋能""抓手""打造闭环"
- 高频踩雷词："说白了""意味着什么？""这意味着""本质上""换句话说""不可否认"
- 空泛工具名："AI 工具"、"某个模型"
- 编造场景：搜不到的信息标注"该信息暂缺"

---

## 7. 终止条件

```
新增率 = 本轮新增问题数 / 上轮总问题数
连续 3 轮新增率 < 50% → 停止
```

覆盖度补搜不计入新增率统计。
