## 6. 流程发现与修复

### 6.1 抽取阶段 — 重大修复
**问题**：`mfk.com` 页面是「专家答疑 + 相关推荐」聚合页，底部会嵌入站内推荐的其他不相关问题（如「铁蛋白高吃什么水果好」「嗓子不好吃什么水果好」「正常体重是多少」），以及免责声明（`7.6本站有权于任何时间...`）和 JS 代码片段。

**修复**：
1. `question_extractor.py` 增加 `is_obviously_not_question()` 过滤 footer / 免责声明 / JS / 链接 / ICP 备案
2. `is_relevant()` 引入核心词表（减脂/减肥/瘦身/燃脂/塑形...）做主题相关性预筛——任何不含核心词的问题直接丢弃
3. `clean_tail()` / `clean_head()` 清理「- 民福康」「展开」「此刻新闻」等噪声前缀后缀
4. `clean_head()` 同时去引号、反问/引述前缀（"可是"、"那么"、"反之"）

**效果**：
- 候选从 200+ 噪声 → 80 候选
- 噪声问题（如"老人吃什么补钙"、"无锡哪家医院看焦虑症"）全部被剔除

### 6.2 频次门槛 — 状态设计
**当前规则**：
- `confirmed` = 含一手源 OR 二手源≥2 OR 三手源≥3
- `pending_validation` = 未达门槛但问题真实
- single_source 高价值问题可入选主清单（status=single_source）

**当前分布**：confirmed 7，pending 46。大部分 pending 是因为来源 URL 多在同一站点（如 mfk.com 多个页面），系统判定为单源。但人工 review 后确认这些 pending 问题是**真实用户问题**，只是来源多样性未达门槛。

### 6.3 反问/修辞检测 — 加强
**修复**：`judge_questions.py` RHETORICAL_PATTERNS 新增 `何异于`、`不夸张地`、`教你`、`怎么辨别` 等模式。
**效果**：4 条修辞反问题被 QM3-B 拒绝（如「不夸张地说，这样的快速瘦身，何异于谋财害命？」）。

## 7. 覆盖度改进建议

剩下 7 个空缺格子需要更多针对性搜索：
- **基础 / Why、Who、How**：需要更学术 / 官方的"原理"页面（如知乎专业解答、运动医学教材）
- **旅程 / 执行期、瓶颈期、维持期**：需要更实操指南（如知乎专栏、健身博主深度文章）
- **争议时效 / 时效**：需要历史溯源（如「中国减肥观念演变」「2025 GLP-1 减肥药」）

补搜方向：增加知乎 / 36kr / 丁香医生 / 澎湃等深度来源的 URL，每个格子再补 2-3 条，预计能把覆盖率推到 13/16 ~ 15/16。
