## 3. 抽取阶段新发现的问题与修复

### 3.1 「人民号平台下载客户端」前缀
**问题**：人民网/今日头条页面顶部有「人民号平台下载客户端」导航文本，被错误抽取。

**修复**：`clean_head` 增加客户端前缀清理：
```python
r"^(人民号平台下载客户端|客户端|下载.*客户端|打开.*App|扫码下载)"
```

### 3.2 列表符号前缀（· • ● ○）
**问题**：医学文章常使用 `·芹菜降血压？` `•洋葱能降压？` 这类列表小标题。

**修复**：清理 `^[·•●○▪▫\-\*•]+\s*`

### 3.3 章节中文数字（一、二、三、）
**问题**：「一、洋葱降血压，是真的吗？」中的「一、」是文章章节编号。

**修复**：清理 `^[（(]?[一二三四五六七八九十百零]+[）)]?[、\.\s]+`

### 3.4 「参考资料：[1]」引用标记
**问题**：科普文章末尾的「参考资料：[1] 高血压的饮食管理. 四川省骨科医院. 2021-12-31」被错误抽取。

**修复**：清理 `^参考资料[：:]\s*` 和 `\[\d+\]`

### 3.5 效果
抽取阶段从 11 个有噪声问题 → 21 个高质量候选 → 20 个真问题 → **95% 抽取精度**。
