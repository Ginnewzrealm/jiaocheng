## 3. 抽取阶段发现的特殊问题

### 3.1 维基百科脚注引用片段
**问题**：维基百科正文包含 `^ 7.0 7.1 首張專輯《Jay》問世 20 週年...` 这种脚注引用标记，会被误判为问题。

**示例（被过滤前）**：
- `^ 周杰倫新專輯《太陽之子》命名由來和歌神張學友有關？`
- `^ 周杰倫娶昆凌？`
- `^ 受昆凌感召？`
- `直到昆凌成年後在2010年拍攝MV〈你好嗎？`（句子片段 + 书名号片段）

**修复**：在 `NON_QUESTION_PATTERNS` 增加：
```python
r"^\s*\^[\s一-龥]",                     # ^ 后跟中文（维基脚注引用）
r"^[\^＊\*]+\s*[一-龥]",                 # 脚注符号 + 中文
r"^\s*受[^\n]{0,50}[？?]\s*$",           # 句子片段：受...感召？
r"^\s*直到[^\n]{0,50}[？?]\s*$",         # 句子片段：直到...
r"^.{0,40}[〈《].{0,15}[？?]\s*$",        # 含书名号 + 短片段
```

**效果**：4 个脚注引用片段全部被过滤，confirmed 归零，但质量大幅提升。
