## 6. 关键发现

### 6.1 confirmed = 0 的原因
- 所有 19 个问题的 source_count = 1（即单一 URL）
- 频次门槛要求 tertiary 类型 ≥3 频次
- 需要补搜更多重复 URL 才能让相同问题被多次发现

### 6.2 行业主题的特征
- 文章多为导购/分析（"哪个牌子好"、"怎么选"、"保值率"），不是问答社区
- 真问题多隐藏在**文章小标题**、**FAQ 段落**、**用户评论**中
- 反问标题（如"Model 3毛坯房再降级？"）要靠 QM3-B 检测

### 6.3 question_extractor 强化效果
- smart quote 切分（`""` `''` `「」` `『』` `（）`）让引号内的真问题能正确切分
- 多轮 FAQ/编号清理（5 轮）解决嵌套前缀问题
- 章节编号（`05 常见问题FAQ`）现在能完全清理

### 6.4 反问/修辞检测生效
- 「特斯拉Model 3毛坯房再降级？」「十万级纯电SUV遍地低价陷阱」等反问标题未通过 strict 问号过滤 → 仍出现在 pending（因为以？结尾）
- 后续可考虑加入「标题反问」启发式（不以「吗/呢/为什么」结尾但带「？」的更可能是反问）
