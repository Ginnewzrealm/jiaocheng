# 采集失败与后处理

失败先看 harvest-one 的分类；单独排障可用 explain --file。没有结果文件时也要查看 CLI 的 stderr；非零退出不能复用旧成品冒充本次成功。

| 分类 | 动作 |
|---|---|
| quota | 不原地重试，检查套餐和配额，或换可用通道 |
| blocked | 同通道不反复重试，换浏览器/collector；学术源有可靠同 ID 镜像时自动尝试一次 |
| thin | 判断短小的真实文档还是渲染墙；前者显式调整阈值并记录依据，后者换浏览器 |
| empty/tool_error | 检查命令、依赖、网络与 stderr，不能靠文件大小推断成功 |
| incomplete | 站点采集未完成或仍有分页，先检查任务状态，不反复新建付费任务 |
| opencli/collector | 已转交 Agent，采完必须 register，不属于已完成自动采集 |
| redundant/skip-book | 记录跳过，不进入重试队列 |

临时网络错误最多同通道重试一次。502/503 可以尝试本机浏览器；404/410 先核实原 URL，再记失败或替补。可用通道都失败时报告缺口，不无限尝试；替补关系和失败源都保留。

PubMed/PMC 可经 Europe PMC 同 PMID/PMCID 镜像补采；同标识不保证各站展示文本完全一致，记录实际获取 URL（via）和本地快照。Lancet 付费墙没有可确认镜像时转浏览器或人工下载，不能猜造镜像。

后处理去空锚点、保留站内链接显示文本、保留外部引用 URL；域名必须精确匹配。无 site-host 时只去空锚点。后处理后的正文再次验收，来源头不计入正文长度。

每次执行使用隔离的临时响应文件，已有同 URL 成品不因一次网络失败被当作新成功。文件名附 URL 摘要，防止同名页面互相覆盖。成品改变须重新 register，然后重跑 manifest 和下游检查。
