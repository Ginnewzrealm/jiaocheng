# gin-qc：单篇活人感终检

对一篇正文跑**四层活人感体系**（改造自 gin-wechat-article-quality，公众号专属规则
已剔除）。核心原则：**机器管机器管得了的（节奏/密度/灰度），人管机器管不了的
（温度/独特/姿态/心流）——L4 四项永远出报告、永远人审。**

## 与 gin-draft 的分工（设计决策）

| | gin-draft（Stage 5） | gin-qc（Stage 6） |
|---|---|---|
| 回答的问题 | 这篇**构件合格吗** | 这篇**读起来像人写的吗** |
| 检查 | 锚定率/篇首契约/篇末交付物/案例出场/句式密度/禁区词 | 段落/句长节奏/疑问句/证据密度/绝对化/称呼/结构整齐 |
| 时序 | 写作期边写边检 | 成稿后终检 |

禁区词只在 gin-draft 检（写作期就拦），本层不重复。

## 工作流程

```
1. 读篇    一篇 Markdown 正文（已过 gin-draft 机检）
2. 机检    python3 scripts/qc.py check --file <篇.md>
           → errors 不归零不出报告；warnings 每项 -5
3. 出报告  score + verdict + L4 四项人工判断项
4. 人审    【硬闸门】用户逐项过 L4：温度感/独特性/姿态/心流
           ——机检"通过"不等于可发布
```

## 四层机检规则（全部有回归测试）

| 层 | 规则 | 级别 |
|---|---|---|
| L1 | 段落 ≤300 字（文字墙拆开） | ❌ hard-fail |
| L2 | 长短句交替：≥70% 句子挤在中位数 ±20% 内 = 整齐节奏（防塞超长句拉方差） | ⚠️ -5 |
| L2 | 零疑问句 = 单向输出无对话感 | ⚠️ -5 |
| L3 | 证据密度：每 800 字 ≥1 **行**含真数字，按行分布 | ⚠️ -5 |
| L3 | 认知灰度：一定/绝对/百分百/必然/肯定会（"不一定"豁免） | ⚠️ -5 |
| L3 | 身份共鸣：≥300 字篇"你" <2 次 = 教科书腔 | ⚠️ -5 |
| L3 | 两个列表块背靠背、中间无正文 = 结构过分整齐 | ⚠️ -5 |
| L2 | **扣主线句缺席**（hv-analysis 节奏观）：≥5 行散文却几乎不回扣篇题词 = 形散神也散 | ⚠️ -5 |
| L3 | **未标注推测**（hv-analysis"敢下判断"）：对未来下强断言却无"可能/推测/证据有限"标注 | ⚠️ -5 |
| L3 | **排比三连**（2026-09-12 调研）："不仅…更…还…"式同构并列 ≥2 处/篇 = AI 腔典型骨架 | ⚠️ -5 |
| L3 | **段末总结口头禅**：>30% 段落以"所以/也就是说/这意味着"收尾，段段有小结是 AI 骨架 | ⚠️ -5 |
| L3 | **"让我们"邀请句**：AI 讲解标志性起手式，真人教程几乎不用 | ⚠️ -5 |
| L3 | **程度副词堆砌**：非常/十分/极大地/显著 ≥3 次/篇（"很"不算，真人口语） | ⚠️ -5 |
| 排版 | **标题层级跳级**：H2 直接下 H4 ❌——层级必须连续 | ❌ hard-fail |
| 排版 | **孤立 H3**：全文仅 1 个 H3 无配对——H3 只在步骤分组需要导航时才上 | ⚠️ -5 |
| 排版 | **方法节缺步骤**：标题带"怎么/如何/算出"等动作词的小节通篇无有序列表——"怎么做"必须步骤呈现 | ⚠️ -5 |
| 排版 | **加粗密度**：>10 处/千字——满地加粗=处处强调=无强调 | ⚠️ -5 |

### 证据密度口径（防凑数，重构期实测）

- **不算数**：L1-L7/ 素材路径、（2024）式引文年份标注——贴来源凑不出证据。
- **一行贴满不算数**：按"含真数字的行数"计，每 800 字至少 1 行，且要分布在
  正文各处——"数据：8公斤 200千卡 1200千卡"一行贴完照样命中。

## 评分与判定

- score = 100 - 5 × warning 数；任一 error → 直接**不通过**
- ≥85 通过；70-84 通过但提示 minor 问题；<70 不通过，返回修改
- **verdict 只是机检结论**：L4 四项（温度感/独特性/姿态/心流）不进评分，
  必须在报告里逐项人审后才算终审完成

## L4 活人感终审（人工判断，永远不进机器评分）

1. **温度感**：情绪表达是体感记忆还是知识性描述？
2. **独特性**：是否有只有这个作者才会写出来的角度？
3. **姿态**：是否滑入"导师教学生"或"品牌做营销"的姿态？（hv-analysis 谦逊铺垫：教程文开头有没有卸傲慢？）
4. **心流**：篇内通读，注意力有没有断掉？（整篇通读归装配层）
5. **叙事弧线**：这篇是故事驱动还是流水账？（hv-analysis"叙事驱动非罗列驱动"）
6. **对立面承认**：给建议前有没有先承认"不这么做的人也合理"？（hv-analysis）

## 实测发现（2026-09-06 狗粮）

- 过 gin-draft 的实战章（减脂平台期 ch1）：score 100 通过——两阶段规则无冲突。
- 红阶段裸写章（gin-draft 判 4 错误 1 警告）：本层 score 100。说明它的问题是
  **构件不合格**（无出处/无契约/无交付物），不是 AI 腔——两层检的是不同维度，
  缺一不可，不可替代。

## 边界

- 只报告不改写（wechat 系"内容类问题不自动修复"原则沿用）
- 不检构件项（gin-draft 的地盘）、不组书（装配层未来另建）
- 整篇心流检查在装配层；本层 L4 心流降级为篇内通读

## 依赖

- 上游：gin-draft 出的篇构件（先过构件机检再来活人感终检）
- 人审节点：用户终审（硬闸门）
