# gin-draft：教程章节写作（章构件）

按大纲施工单写**一章**正文。核心原则：**章是装配无关的构件——单篇教程和未来的书
都从同一套章构件装配，本技能只管"这章本身合格不合格"，不管它最后属于谁。**

方法论来源：X 三篇对标实拆（LanyXiaosheng / AdrianPunk115 / miles_mazy）的六条
可机检风格规则 + 卡兹克文风禁区词表（hv-analysis 现成表）。

## 边界声明（设计决策，用户认可）

- 本技能只生产**章构件**，不管这章属于单篇教程还是书。
- 装配（串篇/组书/全书结构）是上层的事，未来书籍装配层**不动本脚本一字**。
- 章用得好不好（案例融入度、节奏、活人感）归 Stage 6 质检，本层只机检可机检项。

## 何时使用 / 不适用

- 大纲在手，按图施工写某一章 → 本技能
- 还没有大纲 → 先 gin-outline（本技能不内嵌排章）
- 要终稿质检 → Stage 6（本层过了不等于能发）

## 工作流程

```
1. 读施工单  大纲.json 里本章的：章标题、目标（动作动词）、卡片（讲什么）、素材（用什么讲）
2. 读素材    从资料库读齐本章素材文件（卡片给论点骨架，素材给论据血肉）
3. 写正文    章首契约 → 素材锚定的论述 → 贯穿案例穿插 → 章末交付物
4. 机检      python3 scripts/draft.py check --file <章.md> --materials <n或路径列表>
             [--library <资料库>] [--case <贯穿案例名>]
             → errors 不归零不出件
```

## 风格六条（全部来自三篇对标实拆，机检可判）

| # | 规则 | 机检 |
|---|---|---|
| 1 | 章首两件套：写给谁 + 读完能做到什么（前 5 行内） | ❌ 缺契约不出件 |
| 2 | 章末可拿走交付物：自查清单 / 判断表格 / 可复制模板 | ❌ "本章要点"不算 |
| 3 | 贯穿案例出场 ≥1 次（大纲钉死的案例人物） | ❌ 零出场不出件 |
| 4 | 素材锚定率 ≥60%：关键论断带来源标注（出处/《名》/研究（年份）/L 路径） | ❌ <60% 不出件 |
| 5 | 「不是A，是B」密度 ≤2 次/章——单句是好修辞，密了是口头禅 | ⚠️ 超了警告 |
| 6 | 卡兹克禁区词表：说白了/本质上/换句话说/不可否认/意味着/赋能/抓手/打造闭环/综上所述/首先/其次/最后/值得注意的是/不难发现/在当今/随着技术 | ⚠️ 命中警告 |

## 机检规则溯源（红阶段基线实测，2026-09-06）

基线 = /tmp/gin-draft-baseline/ch1.md（"平台期"第一章裸写）五条真实失败：

| 失败 | 规则 |
|---|---|
| F1 开篇直接讲故事，没写给谁 | 规则 1 章首契约 |
| F2 章末只有"本章要点" | 规则 2 交付物 |
| F3 大纲钉了"小张"，正文零出场 | 规则 3 案例在场 |
| F4 通篇论断零出处 | 规则 4 锚定率 60% |
| F5 「不是A是B」一章 5 次 | 规则 5 密度上限 |

## 锚定率口径（防凑数，重构期实测）

- 分母 = 本章素材份数 × 2（每份素材 2 处锚点 = 满分），封顶 100%。
- 宽口径命中：「素材：」「出处：」「根据《×》」「（含年份）」「L1-L7/ 路径」「研究表明/发现/显示」。
- **只堵清单式贴名**：头部带"素材/出处/来源/参考/引用"标签的行、或一行并列 ≥2 个
  L 路径（、/，连接）的行，最多算 1 锚点——锚定必须分布在正文里，不能章末贴一行糊弄。
- 正文里一句真引用连标几处照实计数（一句话多处标源是好的）。

## 口吻选择（按问题类型，不写进机检）

- 事实型/解释型章节 → miles_mazy 解释者风（第一人称集中，拆解给外行听）
- 方法型/争议型章节 → Lany / Adrian 案例实战风（反向判断密度高：不必/不要/没必要/不适合）
- 共性：NextSteps 结尾、数字具体到个位数（"3 周"不写"一段时间"）

## 常见错误（红阶段基线实测）

| 错误（基线实际行为） | 纠正 |
|---|---|
| 开篇叙事 hook 当契约 | "写给谁"和"读完能做什么"两句都必须在场 |
| 章末"本章要点" bullet 交差 | 要点是回忆，交付物是能拿走用的（清单/表/模板） |
| 案例人物只在别的章出场 | 每章独立机检，本章零出场就是不出件 |
| 章末贴一行素材清单凑锚定 | 清单行只算 1 锚点，正文分散标注才算数 |
| 引用了素材但没标出处 | 「（出处：L3/科学网）」这类标注要落在论断旁 |
