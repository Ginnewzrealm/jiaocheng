# 教程评估样本

当前仓库保留了 gin-question 的真实主题评估输出；它们是问题发现阶段样本，不能用来证明最终教程的学习效果。旧测试引用的减脂章节未随库分发，不能以合成文本冒充它们。

tests/pipeline_fixture.py 是可复现的合成操作教程，用真实 Python 输出验证工程协议与失败分支。它不代表真实用户的完成率或文风基线。其他原型的结构与状态由单元／集成用例验证，学习效果还需真实样本。

新增真实样本时按 samples.json 的格式记录稳定 ID、原型、领域、出处、取得日期、内容哈希、许可及用途。无法确认再分发许可时只记录链接和测量结果，不复制全文。区分规则开发集与保留评估集，避免在同一批样本上定规则又宣布效果。

测量记录至少包含：读者目标、环境／前置能力、实际任务结果、卡住的步骤、检查规则的误报／漏报、证据复核结论。结果未测就填 null，不能把未验证算作失败或成功。规则阈值先作诊断，积累跨原型样本后再考虑升级为硬约束。

规范来源与规则应能追溯到实际失败样本；当前已修问题的回归用例在 tests/test_pipeline_contracts.py。没有样本时不要编造均值、完成率或“优秀教程”的统计规律。
